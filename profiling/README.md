# Profiling heap-js

## Profiling with 0x

```
0x -o profiling/0x.mjs
```

The output is not great with [`0x`](https://github.com/davidmarkclements/0x)
for some reason, so I've also added HTML files which import the heap
implementations and that can be opened in a chromium browser that has a
built-in profiler. This profiler shows much more information than 0x. 

## Profiling with chromium browser

The trace output of each of the implementations are the JSON files in this
directory. These can be loaded in to chromium browsers under the
"Performance" tab in the dev tools, then clicking the upload icon. The
files under "sources" will then show time consumed to the left of each
line it sampled.

Both heap-js.html and heap.html push 100 thousand numbers, then pop them.
The traces were ran at 20x CPU slowdown so that the profiler catches more
samples within the pushing and popping itself.

The HTML files can be opened directly in the browser, then a trace can be
generated by going to the Performance tab in the dev tools and clicking
the record icon.
